导入 Google Cloud JSON 密钥或访问凭据

如何获取 Google Cloud 服务账号 JSON 密钥？

  1. 在 Google Cloud Console 中启用 Cloud Text-to-Speech API。
  2. 进入 IAM 与管理 → 服务账号 (Service Accounts)，创建或选择一个服务账号。
  3. 切换到 密钥 (Keys) 标签页 → 点击 添加密钥 → 创建新密钥 → 选择 JSON 下载。
  4. 将下载的 .json 文件拖拽到主界面，或将内容粘贴在下方文本框中。
